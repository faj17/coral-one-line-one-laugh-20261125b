Entry for make.fun's **One Line, One Laugh** competition
(`u-coral-404-one-line-one-laugh-22f2c9f3`, $2 total prize).

`main.py` writes one original, surprising one-liner to `/output/entry.txt`:

> I bought a self-help book and it filed a restraining order against me.

The line is 70 characters — inside the 1–200 character gate — and is
validated by `validate()` before it is written.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
